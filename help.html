Documentation de Référence

Tout ce qu'il faut savoir pour maîtriser le Logo VL Advanced.

📝 Syntaxe et Concepts de Base

Le langage Logo VL Advanced est un dialecte moderne du Logo, inspiré du français mais compatible avec les commandes classiques en anglais.

  • Sensibilité à la casse : Les commandes et mots-clés sont insensibles à la casse (av ou AV), mais l'éditeur les convertit automatiquement en majuscules pour plus de clarté.
  • Variables : Les variables commencent par deux points :nomVariable.
  • Chaînes de caractères : Utilisez des guillemets (ex: "Bonjour") ou le style Logo classique (ex: "Texte).
  • Commentaires : Utilisez // pour un commentaire sur une seule ligne.
  • Séparateurs : Les espaces séparent les arguments. La virgule , est optionnelle mais recommandée pour la clarté (ex: FPOS 100, -50).

↔️ Mouvement de la Tortue

Commandes (FR / EN)ArgumentsDescription
AV / FDnAvancer de n pixels.
RE / BKnReculer de n pixels.
TD / RTangleTourner à droite de angle degrés.
TG / LTangleTourner à gauche de angle degrés.
FPOS / SETXYx, yPlace la tortue aux coordonnées (x, y).
FCAP / SETHEADINGangleDéfinit l'orientation (0 = haut, 90 = droite).
ORIGINE / HOME-Retourne au centre (0, 0) et regarde vers le haut.
CT / HT-Cache la tortue (Cacher Tortue / Hide Turtle).
MT / ST-Montre la tortue (Montrer Tortue / Show Turtle).
POSX / POSY-Retourne la coordonnée X ou Y actuelle.
CAP / HEADING-Retourne l'angle actuel de la tortue.
DISTANCE / DSx, yCalcule la distance entre la tortue et le point (x, y).
VERS / TOWARDSx, yRetourne l'angle nécessaire pour pointer vers (x, y).
PAUSEmsAttend ms millisecondes avant de continuer.
Exemple : Déplacement basique
// Dessiner un escalier
REPETE 5 [
  AV 20
  TD 90
  AV 20
  TG 90
]
Exemple : Utilisation des coordonnées
VE // Vide l'écran
FPOS -100, 100
ECRIS POSX // Affiche -100
TD VERS 0, 0 // S'oriente vers le centre
AV DISTANCE 0, 0 // Avance jusqu'au centre

🧮 Mathématiques et Logique

Le Logo VL Advanced supporte les opérateurs standards : +, -, *, /, % (modulo), ^ (puissance).

FonctionArgumentsDescription
SIN / COS / TANangleTrigonométrie (angle en degrés).
RACINE / SQRTnRacine carrée de n.
VALABS / ABSnValeur absolue.
ARRONDI / ROUNDnArrondit à l'entier le plus proche.
ENTIER / INTEGERnPartie entière (tronque).
HASARD / RANDOMmaxNombre aléatoire entre 0 et max.
PI-La constante Pi (~3.14159).
MODULO / MODa, bReste de la division de a par b.
Exemple : Calculs
DONNE :r 50
DONNE :surface PI * (:r ^ 2)
LOG "Surface : " + :surface

// Position aléatoire
FPOS (HASARD 200) - 100, (HASARD 200) - 100

Les tableaux permettent de stocker des listes de valeurs.

DONNE :couleurs TABLEAU

TAB_AJOUTE :couleurs "vert"
TAB_AJOUTE :couleurs "bleu"

REPETE TAB_TAILLE :couleurs [
  FCC TAB_LIS :couleurs _i0
  AV 50 TD 90
]

🔄 Structures de Contrôle

Boucle REPETE

Répète un bloc de code un nombre défini de fois. La variable _i0 (puis _i1, etc. pour les boucles imbriquées) contient l'index actuel.

REPETE 10 [
  ECRIS _i0
  AV 10
]

Conditions SI / SINON

Exécute du code selon une condition.

SI :x > 100 [
  LOG "Trop grand !"
] SINON [
  AV :x
]

Boucle TANTQUE

Répète tant qu'une condition est vraie.

TANTQUE :distance < 200 [
  AV 10
  DONNE :distance :distance + 10
]

Sélecteur CHOISIS (Switch)

Permet de tester plusieurs cas pour une valeur.

CHOISIS :touche [
  CASE "a" [ TG 90 ]
  CASE "d" [ TD 90 ]
  AUTRES [ AV 10 ]
]

Mots-clés de boucle : STOP et CONTINUE

  • STOP : Arrête immédiatement la boucle en cours.
  • CONTINUE : Passe immédiatement à l'itération suivante.

📦 Procédures (Fonctions)

Définissez vos propres commandes avec POUR et FIN.

Définition d'une procédure
POUR CARRE :taille
  REPETE 4 [
    AV :taille
    TD 90
  ]
FIN

// Appel de la procédure
CARRE 50
CARRE 100
Procédure avec retour de valeur
POUR DOUBLE :n
  RENDS :n * 2
FIN

DONNE :resultat DOUBLE 21
LOG :resultat // Affiche 42

🏗️ Programmation Orientée Objet

Logo VL Advanced supporte la création de classes pour organiser votre code.

CLASSE Robot [
  constructeur [
    DONNE this.nom "Bot"
    DONNE this.x 0
  ]

  avancer [
    DONNE this.x this.x + 10
    LOG this.nom + " est à " + this.x
  ]
]

DONNE :monRobot new Robot()
:monRobot.avancer()
