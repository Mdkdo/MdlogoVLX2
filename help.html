Documentation de Référence

Guide complet du langage Logo VL Advanced.

Syntaxe de base

  • Variables : Débutent par : (ex: :x).
  • Commentaires : Débutent par //.
  • Sensibilité : Les commandes sont insensibles à la casse.

🔄 Structures de Contrôle

Boucles et Conditions

REPETE 4 [ AV 100 TD 90 ]

SI (:x > 10) [ AV 100 ] SINON [ RE 100 ]

TANTQUE (:x < 100) [ :x++ ]

CHOISIS (:val) [
  CASE 1 [ AV 10 ]
  AUTRES [ RE 10 ]
]

STOP // Arrête la boucle
CONTINUE // Passe à l'itération suivante

🏗️ Procédures et Classes

Procédures (POUR ... FIN)

POUR CARRE :taille
  REPETE 4 [ AV :taille TD 90 ]
FIN

RENDS 42 // Retourne une valeur ou arrête la procédure

Classes (CLASSE ... [ ... ])

CLASSE Point [
  constructeur [ this.x = 0 ]
  setX [ DONNE this.x 10 ]
]
